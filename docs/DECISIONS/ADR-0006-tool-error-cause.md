# ADR-0006: Причина ошибки исполнения инструмента

- Статус: Accepted
- Дата: 2026-10-29
- Утвердил: владелец проекта в чате

## Контекст

Runtime преобразует исключение `AgentTool.execute()` в безопасную `AgentRuntimeError` с кодом `TOOL_EXECUTION_FAILED` и фиксированным сообщением. Исходная причина теряется, что мешает диагностике ошибки вызывающим application code.

## Варианты

1. Отбрасывать исходную причину — сохраняет безопасную границу, но теряет диагностическую информацию.
2. Подменить безопасное сообщение текстом исходной ошибки — облегчает диагностику, но может раскрыть внутренние данные через CLI.
3. Сохранять исходное значение в стандартном `Error.cause`, не меняя код и сообщение — даёт вызывающему коду доступ к диагностике, сохраняя внешний ответ CLI.

## Решение

- Исключение из `AgentTool.execute()` передаётся как `cause` в `AgentRuntimeError`.
- Код `TOOL_EXECUTION_FAILED` и безопасное сообщение остаются неизменными.
- CLI сериализует только прежний код и сообщение; cause не включается в пользовательский вывод.

## Последствия

- Внутренние application callers могут исследовать исходную причину ошибки.
- Вызывающий код должен обращаться с `cause` как с диагностическими данными и не включать его в пользовательские сообщения или логи без фильтрации.
- Для отката достаточно перестать передавать `cause` при создании `AgentRuntimeError`; остальные коды и поведение хода не меняются.
