# ADR-0008: Shell и компактная лента агента

- Статус: Accepted
- Дата: 2026-10-29
- Утвердил: владелец проекта в чате

## Контекст

Статический React preview из ADR-0007 должен дать оценить не только отдельный transcript, но и оболочку приложения: проекты и сессии, разные представления хода агента, компактные tool-call статусы и постоянно доступную область ввода. Реального Application API пока нет.

## Варианты

1. Оставить один transcript и только добавить визуальные секции. Это не позволяет оценить навигацию и альтернативное представление хода.
2. Добавить локальную модель фиктивного workspace, переключаемые вкладки «Чат» и «Траектория» и адаптивную оболочку. Это расширяет только UI preview и не создаёт backend-контракт.

## Решение

- Добавить демонстрационные проекты и сессии с локальным переключением активного чата.
- Строить оба представления из одной модели шагов: «Чат» показывает сообщения и компактные строки действий, «Траектория» раскрывает подробности reasoning и tool calls.
- Представить состояния `running`, `success` и `error` подписью и небольшим значком с умеренным использованием цвета.
- Удерживать read-only composer в отдельной нижней области; разрешить скрытие sidebar на широком и узком экране.
- Сохранять маркировку `DEMO`; не импортировать Core/Application типы и не менять Core, Application, JSON storage или зависимости.

## Последствия

- Смена проектов, сессий и вкладки работает только в локальном React state.
- Статусы `running`, `success` и `error` относятся к отдельным вызовам инструментов; сессия не получает общего статуса, поскольку в ней могут быть разные ходы.
- При будущем подключении application API понадобится отдельный адаптер от реальных результатов к UI-модели.
