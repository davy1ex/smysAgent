# ADR-0005: Явный CLI smoke-инструмент `demo.add`

- Статус: Accepted
- Дата: 2026-10-28
- Утвердил: владелец проекта в чате

## Контекст

Ограниченный agent loop доступен через application API, но CLI не предоставлял инструмент для ручной проверки. Для smoke-сценария нужен один безопасный инструмент, не включённый по умолчанию и не меняющий runtime или лимиты.

## Варианты

1. Оставить проверку только на уровне application tests — не позволяет запустить CLI-сценарий с реальной моделью.
2. Добавить общий CLI registry или множество инструментов — слишком широко для smoke-теста.
3. Встроить один инструмент `demo.add` с отдельными флагами подключения и разрешения — ограниченный проверяемый CLI-сценарий.

## Решение

- `--tool demo.add` явно передаёт описание инструмента модели.
- `--allow-tool demo.add` отдельно разрешает выполнение. Если инструмент подключён без этого флага, CLI передаёт политику, которая отклоняет его вызов. `--allow-tool` без `--tool` отклоняется как ошибка аргументов.
- Без обоих флагов CLI передаёт пустой список инструментов и сохраняет прежнее поведение.
- `demo.add` принимает ровно два конечных числовых свойства `a` и `b`, не принимает дополнительные поля и возвращает сумму текстом.
- Fake provider при явном подключении выполняет детерминированный smoke-сценарий `demo.add(2, 3)`; обычный fake ход остаётся текстовым.
- LM Studio получает обычное описание инструмента и может вызвать его через существующий tool-calling контракт. Пользовательский prompt просит модель выполнить сложение; исполнение всё равно требует флага разрешения.
- Agent runtime, provider protocol, лимиты, формат store v2 и зависимости не меняются. Этот ADR заменяет утверждение ADR-0004 о том, что CLI не регистрирует инструменты.

## Последствия

- CLI smoke-путь проверяет сборку application use case, runtime permission gate, выполнение инструмента и сохранение финального ответа.
- Автоматические проверки не зависят от LM Studio; live-вызов запускается пользователем отдельной CLI-командой.
- Встроенный `demo.add` — диагностический инструмент, не plugin API и не начало общего реестра инструментов.
