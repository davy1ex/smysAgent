# ADR-0010: End-to-end text streaming

- Статус: Superseded by ADR-0012
- Дата: 2026-10-30
- Утвердил: владелец проекта в чате

## Контекст

Web-клиент SMYS должен показывать текст локальной модели по мере генерации. Существующий `generate()` и JSON endpoint используются CLI, tool calling и интеграционными проверками; потоковый текст не должен менять их поведение. Частичный ответ не является сохранённым сообщением.

## Варианты

1. Заменить ответ существующего Web endpoint на SSE — меньше маршрутов, но несовместимо с его JSON-контрактом и текущими callers.
2. Добавить отдельный `POST /api/sessions/:id/messages/stream` — сохраняет JSON endpoint и даёт Web-клиенту POST с телом запроса.
3. Передавать только завершённое сообщение JSON и обновлять UI опросом — не даёт настоящей потоковой выдачи.

## Решение

- Сохранить `TextGenerationProvider.generate()` и текущий `POST /api/sessions/:id/messages`.
- Добавить внутренний `StreamingTextGenerationProvider.streamText()` и Application use case `runAgentTurnStreaming()`.
- Добавить локальный SSE endpoint `POST /api/sessions/:id/messages/stream`; Web читает его через `fetch()`.
- В B1 потоковый режим поддерживает только текстовые ответы без tools. Tool calling и CLI остаются на `generate()`.
- Передавать текстовые чанки как временные UI-данные. Сохранять объединённый ответ ассистента ровно один раз после корректного окончания потока; отправлять `turn.completed` только после успешной записи.
- Передавать `AbortSignal` от Web host до provider. Ошибка или отмена до записи финального ответа оставляет только сохранённое user message.
- Не менять формат JSON store и не добавлять зависимости.

Минимальные SSE события B1: `turn.started`, `assistant.delta`, `turn.completed`, `turn.failed`. События вызова модели, разрешений и инструментов относятся к следующему этапу.

## Последствия

Web API получает дополнительный HTTP-контракт; SSE ошибки после отправки headers передаются как `turn.failed`, поскольку HTTP status уже установлен. Провайдер должен поддерживать потоковый интерфейс для использования этого endpoint. Откат состоит в переключении Web-клиента на сохранённый JSON endpoint и удалении streaming endpoint/адаптера без миграции данных.
