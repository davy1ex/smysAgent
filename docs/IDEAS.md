# SMYS — IDEAS / PARKING LOT

> Идеи из Planning Kit и обсуждений. Они не являются обязательствами по реализации и не меняют утверждённый roadmap. Стратегические направления M1–M6 перечислены в [`ROADMAP.md`](./ROADMAP.md).

| Идея | Происхождение / зачем | Статус | Что выяснить перед продвижением |
| --- | --- | --- | --- |
| Свой YouTube-аналитик / альтернатива части vidIQ | Личная потребность и возможный продукт для аудитории канала | `IDEA` | Доступность данных, сокращаемая ручная работа, первый измеримый MVP |
| NotebookLM-подобная база знаний | Работа с видео, транскриптами, источниками и поиском | `IDEA` | Права на контент, форматы источников, локальная индексация |
| AI Footage Finder для редактора | Поиск по собственным видео с preview и вставкой в монтаж | `IDEA` | Выбранный редактор, реальный UX, необходимость нативного плагина |
| Adobe/Premiere integration | Интеграция внутри монтажного редактора | `IDEA` | Точный сценарий и совместимый API |
| Pet поверх ОС | Компактный контекстный интерфейс к SMYS backend | `IDEA` | Полезность, жизненный цикл приложения, opt-in уведомления |
| Logseq Critic | Предложения по забытым или незавершённым заметкам | `IDEA` | Тип графа, сигналы активности, read-only или запись, opt-in |
| Память в Markdown | Переносимые предпочтения и рабочий контекст между сессиями | `IDEA` | Состав данных, согласие, исправление и удаление |
| Сабагенты | Делегирование узких задач и проверка результата | `IDEA` | Эффективность, бюджеты, лимиты и контроль побочных эффектов |
| Cron / heartbeat / proactive triggers | Фоновые задания и возможность агенту писать первым | `IDEA` | Разрешения, частота, scheduler и правила уведомлений |
| Динамическая Plugin System | Устанавливаемые сторонние расширения | `IDEA` | Контракты на реальных интеграциях и модель безопасности; не тождественно будущему M6 Extension API |

## Как продвигать идею

Сформулировать конкретную пользовательскую проблему и критерий результата, проверить небольшой proof of concept, затем получить явное решение владельца о включении направления и создать отдельный spec. Технические контракты утверждаются через ADR.
